Потрібно вписати Firebase конфіг у код файлу

Відкрий файл, знайди FIREBASE_CONFIG на початку тега <script> і встав дані свого проєкту з Firebase Console → Project settings → Web app. Realtime Database має бути увімкнена, правила читання/запису відкриті (для тесту: ".read": true, ".write": true).
