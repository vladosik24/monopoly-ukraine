# Монополія Онлайн — Telegram Mini App

Сучасна українська версія Монополії для Telegram.

## Що є

- Повна логіка гри: кубики, купівля полів, оренда, Chance-картки, в'язниця, банкрутство
- 40 полів з українськими та світовими брендами (Садочок, Живчик, Нова Пошта, OLX, Rozetka, ПриватБанк, Монобанк, Епіцентр, АТБ, Apple, Samsung, TikTok, YouTube тощо)
- Гра з ботами (1–3 боти)
- Темний сучасний дизайн + анімації кубиків
- Чат з емодзі
- Профіль і статистика (зберігається локально)
- Адаптація під Telegram WebApp

## Як запустити локально

Просто відкрий `index.html` у браузері або:

```bash
npx serve .
```

## Як зробити Telegram Mini App

1. Захости файл на будь-якому статичному хостингу (GitHub Pages, Vercel, Netlify, Cloudflare Pages).
2. Створи бота через [@BotFather](https://t.me/BotFather).
3. Команда `/newapp` → вибери бота → вкажи назву, опис, фото і **URL** твого хостингу.
4. Готово — відкривай міні-додаток з бота.

## Подальші покращення (які можна додати)

- Справжній мультиплеєр (потрібен бекенд + WebSocket)
- Голосовий чат (WebRTC)
- Будівництво філій / готелів
- Торги між гравцями
- Більше карток Шансу / Супермаркету
- Рейтинг онлайн
